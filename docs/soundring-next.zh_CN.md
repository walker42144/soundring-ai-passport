# SoundRing：重新设计的交互

本版本使用高对比度播放首页和分组菜单。设备控制已有的 Spotify Connect 播放设备，自身不播放音频。

首页长按确定进入音乐库、播放设备、播放控制、设置和息屏。短按上/下切歌，短按确定播放或暂停，双击确定收藏或取消收藏，长按上/下调整音量。列表用上/下选择、确定打开、长按确定返回；支持分页的列表可长按上/下翻页。

Windows 配对中心可一起或分别配置 Wi-Fi 和 Spotify。设备 USB 连接电脑并打开配对页面后，在应用中输入设备屏幕的配对码。Spotify 使用 PKCE 和由用户自行填写并登记的本机回调地址，无需 Client Secret。工具隐藏 Wi-Fi 密码；设备端凭据仍以未加密 NVS 存储。

设置中可分别调整屏幕调暗和熄灭时间、屏幕亮度，以及常亮和自动同步。常亮时仍按调暗时间变暗；变暗或熄屏后的第一次按键仅恢复屏幕。首页背景随封面颜色缓慢变化。

14 和 20 像素字体除界面文字外还包含 GB2312 一级常用汉字，可改善歌名与歌手名显示，但不保证覆盖任意歌曲元数据。显示、联网、Spotify 授权与控制、TLS 内存和息屏行为仍需要实机验证。`soundring.zh_CN.md` 描述的是旧版界面。
